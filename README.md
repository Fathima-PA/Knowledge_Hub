
# KnowledgeHub – AI Document Assistant

## Project Overview

KnowledgeHub is an AI-powered document assistant that allows users to upload documents and ask questions based on their content.

## Technology Stack

- React – Frontend
- Node.js – Backend
- Express.js – REST APIs
- LangChain.js – RAG pipeline
- ChromaDB – Vector database
- MongoDB – Document metadata
- OpenAI / Local LLM – Answer generation

## Main Features

1. Upload PDF and text documents.
2. Extract text from documents.
3. Split text into smaller chunks.
4. Generate embeddings.
5. Store embeddings in ChromaDB.
6. Retrieve relevant information using similarity search.
7. Generate AI answers using retrieved context.
8. Display answers with document sources.
